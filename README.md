# OpenCV Image Annotator (CLI)

A simple Python command-line application built using **OpenCV** that allows users to load an image and draw geometric shapes or add custom text directly from the terminal.

## Features
- **Draw Line (`L`)**: Draw lines between any two coordinates with custom thickness.
- **Draw Circle (`C`)**: Draw circles with custom center, radius, and thickness (supports filled circles with `-1`).
- **Draw Rectangle (`R`)**: Draw bounding boxes or rectangles using top-left and bottom-right coordinates.
- **Add Text (`T`)**: Overlay custom text with adjustable font size, position, and thickness.
- **Preview & Save**: View the edited image in a window, save it to disk, or do both.
